# Calculator

A simple command-line calculator written in **C**.

The program allows the user to perform basic arithmetic operations through a terminal interface.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero protection
- Continuous calculations

---

## Technologies

- **C**
- Standard C Library
- GCC or another C compiler

---

## Project Structure

```text
01-Calculator/
│
├── src/
│   └── main.c
│
├── README.md
└── .gitignore
```

---

## Compilation

Using GCC:

```bash
gcc src/main.c -o calculator
```

---

## Run the program

### Windows

```bash
calculator.exe
```

### Linux / macOS

```bash
./calculator
```

---

## Example

```text
========================
       CALCULATOR
========================

Enter first number: 10
Enter operator: +
Enter second number: 5

Result: 15
```
