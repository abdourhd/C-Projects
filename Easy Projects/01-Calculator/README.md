# Calculator

A simple command-line calculator written in **C**.

The program allows the user to perform basic arithmetic operations through a terminal interface.

---

## 📌 Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero protection
- Continuous calculations

---

## 🧠 Concepts Practiced

- Variables and data types
- Functions
- `switch` statements
- Loops
- User input
- Input validation
- Arithmetic operators

---

Calculator/

---

## ⚙️ Requirements

- GCC
- A terminal
- Linux, macOS, or Windows with a C compiler

---

## 🔨 Compilation

Using GCC:

```bash
gcc src/main.c -o calculator
```

---

## ▶️ Usage

Run the program:

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

Example:

```text
========================
       CALCULATOR
========================

Enter first number: 10
Enter operator: +
Enter second number: 5

Result: 15
```
